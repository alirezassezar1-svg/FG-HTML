# AnyHTML Forge — سیستم رندر تمیز هر کد و تبدیل به فایل‌های مستقل PWA

پلتفرم AnyHTML Forge اکنون مجهز به سیستم رندر زنده هر نوع کد و تبدیل مستقیم پروژه‌ها به فایل‌های HTML تک‌فایلی با ساختار کامل **Progressive Web App (PWA)** است.

## قابلیت‌های جدید اضافه شده

1. **فعال‌سازی سریع و هوشمند با توکن گیت‌هاب**:
   - تنظیم خودکار مخزن هدف روی `alirezassezar1-svg/Forge_html`.
   - فرم فعال‌سازی فوری توکن در صفحه اصلی (بدون نیاز به ورود به تنظیمات عمیق).
   - تست زنده اتصال، اعتبارسنجی دسترسی نوشتن و ردیابی اکشن‌ها.

2. **سیستم رندر تمیز و جامع برای هر نوع کد (Clean Code Rendering Engine)**:
   - **کدهای ری‌اکت (React JSX / TSX)**: کامپایل زنده درون مرورگر با Babel Standalone و React 18 همراه با فریم‌ورک Tailwind CSS و محافظت با ErrorBoundary.
   - **کدهای وب (HTML / CSS / JS)**: ایزوله‌سازی، ریست هوشمند، ریسپانسیو کامل و اجرای ایمن.
   - **بازی‌های دوبعدی و کانواس (Canvas 2D / Games)**: پشتیبانی از کنترل‌های لمسی موبایل، حلقه‌های بازی و نمایش در اندازه کامل صفحه.
   - **آرشیوها و کدهای خام**: بسته‌بندی در قالب مرورگر فایل جستجوپذیر AnyHTML Explorer.

3. **تبدیل هر برنامه به PWA کامل با قابلیت نصب (Standalone PWA)**:
   - تمامی فایل‌های HTML خروجی دارای **Web App Manifest درون‌خطی** (Inlined Data URI) با آیکون اختصاصی و نام سفارشی هستند.
   - دارای **سرویس‌ورکر آفلاین درون‌خطی** برای اجرای بدون اینترنت.
   - برچسب‌های متای ویژه آیفون و سافاری: `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style` و غیره.
   - بنر شناور درون‌برنامه‌ای نصب PWA برای اندروید، دسکتاپ و راهنمای گام‌به‌گام برای آیفون (Share → Add to Home Screen).

4. **استودیو رندر زنده و PWA (Live Code to PWA Studio)**:
   - تب اختصاصی کدنویسی با پیش‌نمایش بلادرنگ و قالب‌های آماده:
     * 📱 اپلیکیشن تسک‌میت با ری‌اکت و تیل‌ویند
     * 🎮 بازی آرکید فضایی با کنترل لمسی موبایل
     * ⏱️ تایمر تمرکز پومودورو با گرافیک چرخشی
     * 📊 داشبورد آمار و تحلیل مالی
   - امکان شخصی‌سازی نام برنامه، نام کوتاه (حداکثر ۱۲ کاراکتر)، رنگ تم و آیکون قبل از دریافت خروجی HTML.
   - دکمه‌های دانلود فوری، پیش‌نمایش در فریم واقعی آیفون ۱۶، کپی کد و اشتراک‌گذاری.

5. **پشتیبانی PWA برای خود نرم‌افزار**:
   - دکمه نصب مستقیم نرم‌افزار AnyHTML در هدر (`PWAInstallButton`).
   - نشانگر وضعیت آفلاین (`OfflineIndicator`).

## نحوه اجرا

```bash
npm install
npm run dev
```
برنامه روی پورت ۳۰۰۰ اجرا می‌شود.
